二、项目目标与当前完成度

最终目标是“AI 陪用户边听网易云音乐边聊天”，而不是播放结束后写乐评。
用户希望对关键音乐变化作出及时反应，不能接受超过 30 秒的体验延迟。
原计划采用 Python 后端和大模型 API，可选本地小模型；用户表示已有第三方
网易云接口的歌单与歌曲信息能力，但本源码包没有集成或验证这些第三方接口。

当前已完成的是第一块基础能力：仅在本机捕获网易云进程树的声音，连续计算
轻量声学特征，输出变化候选事件。没有实现“完整 AI 陪听助手”。

已完成：
- Windows 进程树 WASAPI loopback 音频捕获。
- 48 kHz、双声道、16-bit PCM 的持续流与受限时长 WAV 录音探针。
- 持续安静、声音开始/恢复、能量升降、频带分布/音色变化、节奏密度变化候选。
- 阈值确认、迟滞、同类事件冷却及全局变化事件冷却。
- 捕获间断、积压和过期音频的检测与重置，不把缺失数据伪造为静音。
- 本地 JSONL 事件日志、控制台读数、已有 WAV 的离线快速回放。
- 可直接调用的 Python 检测器、自动化测试、Windows 双击运行入口。

尚未实现：
- 歌名识别、歌词识别、歌曲绝对播放进度或网易云播放控制。
- 自动副歌识别、情绪理解、乐器识别或完整音乐语义分析。
- 大模型调用、语音合成、语音聊天、语义模型、用户记忆或数据库。
- 第三方网易云 API、登录、账户信息或客户端逆向。

三、不可混淆的边界

1. 检测到能量上升，不等于识别到了副歌。
2. silence_start 只表示持续低电平，不证明用户按了暂停。
3. capture_stalled 表示收不到 PCM，不把它解释为音乐安静。
4. event_time_s 是阈值候选首次满足的时刻；detected_at_s 包含确认窗口。
5. 时间轴是本次采集/回放会话的时间，不是歌曲进度。
6. 音频包处理耗时不是“扬声器发声到 AI 开口”的端到端延迟。
7. 模块是启发式检测器，候选事件可能误报或漏报，不能当成置信概率。
8. 进程包含过滤已启用，但尚未完成其它应用同时发声的对照隔离实验。
9. 不采集麦克风、不注入或修改客户端、不访问登录态，不调用网络或模型 API。
   依赖安装可能需要联网；音频检测本身不联网。
10. 实时 monitor 模式默认不保存原始音频。test_netease_audio.py 的录音模式
    则会生成本地 WAV 和分析 JSON，必须区分这两个入口。

四、文件职责

ProcessLoopback.cs
  C# 原生 Windows 捕获器与 COM 接口声明。仅允许名为 cloudmusic 的目标进程。
  以进程树包含模式捕获；支持二进制 stdout 流或 1～30 秒 WAV 文件。
  使用系统 .NET Framework x64 编译器，不依赖 dotnet SDK。

test_netease_audio.py
  早期音频录制/分析探针，也提供 find_cloudmusic_pid() 和 ensure_helper()。
  monitor_audio.py 依赖这两个函数。虽然以 test_ 开头，它不是 unittest 套件；
  不要误删。PID 自动选择网易云根进程；多个根进程时要求 --pid。
  首次运行实时入口时会按需将 ProcessLoopback.cs 编译成同目录的 exe。

music_context.py
  新增的 GSMTC 只读歌曲上下文读取器。通过 Windows.Media.Control 查询当前系统媒体会话，
  默认仅接受 source_app_user_model_id 中包含 cloudmusic 的会话。提供歌曲名、歌手、
  专辑、播放状态、系统时间线位置（若 API 提供）及 watch() 变化迭代器。
  不捕获音频、不控制播放器；没有时间线时 position_seconds 保持 null，不伪造进度。
  PyWinRT 导入为惰性导入，因此原检测器在未安装 PyWinRT 时仍可运行。

check_music_context.py
  Windows GSMTC 单次诊断入口，输出 JSON；用于先验证当前网易云客户端是否暴露会话。

requirements-gsmtc.txt
  可选 PyWinRT 依赖，仅 GSMTC 模块需要；与原 requirements.txt 分开，避免影响音频检测器。

test_music_context.py

audio_changes.py
  无 Windows 捕获依赖的状态化检测核心；NumPy 特征提取与事件判定。

monitor_audio.py

六、数据流与接口

网易云 cloudmusic 进程树
  -> Windows WASAPI Process Loopback（ProcessLoopback.cs）
  -> NCM1 二进制 stdout 管道
  -> monitor_audio.py 读取线程 + 最多 64 包队列
  -> AudioChangeDetector.feed_pcm16()
  -> ChangeEvent
  -> Reporter / JSONL / 控制台

核心调用示例（pcm_bytes 必须由上游提供，不是字符串）：
  from audio_changes import AudioChangeDetector
  detector = AudioChangeDetector(sample_rate=48000, channels=2)
  events = detector.feed_pcm16(pcm_bytes)
  for event in events:
      print(event.to_dict())

每个流保留同一个 detector，不能每次来一个音频块就新建实例。
PCM 必须为小端、有符号 16-bit、按声道交错，长度必须是完整音频帧的倍数。
feed(samples) 也接受归一化浮点数组，形状为 (frames, channels)。
上游出现丢包后调用 reset(at_seconds, reason)；重置时间不能倒退。

ChangeEvent 字段：
  type                  事件名
  event_time_s          首次满足候选条件的会话时间
  detected_at_s         确认并输出时的会话时间
  confirmation_seconds  to_dict() 添加的确认间隔
  stream_epoch          每次 reset 增加
  evidence              RMS、能量差、频谱距离或节奏密度等声学证据
  time_basis            固定 capture_session_seconds

实时/回放日志按 kind 区分 session、event、status、summary、error。
不是每一行都是事件；下游必须先检查 kind。

七、NCM1 原生流协议

所有数值使用 little-endian，stdout 不得混入文字。
流头共 16 字节，Python 格式 <4sIII：
  magic=b"NCM1"，sample_rate=48000，channels=2，bits_per_sample=16。

每个数据包头共 16 字节，格式 <IId：
  uint32 frames
  uint32 flags
  double received_seconds
随后为 frames * channels * 2 字节 PCM。

flags 低三位保持 WASAPI 标志：1=数据间断，2=显式静音包，4=时间戳错误。
frames=0、flags=0 是心跳，没有 PCM；心跳不表示静音。
frames=0、flags=0x80000000 是正常结束。
received_seconds 是从原生 Start 起计时的接收时间，不是播放软件时间轴。
原生诊断/汇总 JSON 在 stderr；流读取必须支持不完整的分段 read。

首包用 received_seconds - packet_duration 近似锚定采集起点。
读取线程对真正的 PCM 包连续编号；消费者发现实际序号缺口时才重置，
不能用生产者的累计丢包数提前重置仍在处理的连续包。
队列过载丢弃最旧包，超过 0.5 秒队列年龄的包也不再分析。
连续 1 秒无 PCM 报 capture_stalled；恢复后重置而不是补静音。

八、默认检测参数与行为

- 50 ms 特征步长，保留约 8 秒历史。
- RMS 计算响度，频带归一化功率描述音色，瞬态密度描述节奏变化候选。
- 对声道功率求平均，而不是直接混合波形，避免反相双声道互相抵消。
- 安静阈值 -60 dBFS，持续 0.7 秒确认。
- 恢复阈值 -52 dBFS，持续 0.25 秒确认。
- 基线窗口最多 4 秒，排除最近 1 秒，至少要积累 2 秒有效基线。
- 最近窗口 0.4 秒；能量上升默认 +6 dB，下降默认 -8 dB。
- 音色变化使用频带分布的总变差距离，默认阈值 0.38。
- 节奏使用 1.5 秒近期瞬态窗口，不是精确 BPM 或拍点识别。
- 同类变化默认冷却 8 秒；不同变化之间至少间隔 1.5 秒。
- 初次启动/重置需要积累基线，不能立即给出有依据的编配变化。

    private static void WriteHeader(BinaryWriter writer, uint bytes)
    {
        writer.Seek(0, SeekOrigin.Begin);
        writer.Write(Encoding.ASCII.GetBytes("RIFF")); writer.Write(checked(36u + bytes));
        writer.Write(Encoding.ASCII.GetBytes("WAVEfmt ")); writer.Write(16u);
        writer.Write((ushort)1); writer.Write((ushort)2); writer.Write(48000u);
        writer.Write(192000u); writer.Write((ushort)4); writer.Write((ushort)16);
        writer.Write(Encoding.ASCII.GetBytes("data")); writer.Write(bytes);
        writer.Flush();
    }

    private static void CheckOutputPipe()
    {
        // Framework's console stream can swallow broken-pipe errors. A zero-byte
        // native probe emits no protocol bytes but detects a reader/parent exit,
        // including during silence via heartbeat writes. No recorder is left running.
        IntPtr handle = GetStdHandle(-11);
        if (GetFileType(handle) != 3u) return; // FILE_TYPE_PIPE only; not files/consoles.
        uint written;
        if (!WriteFile(handle, IntPtr.Zero, 0, out written, IntPtr.Zero))
        {
            int error = Marshal.GetLastWin32Error();
            throw new IOException("Output pipe write failed: Win32 error " +
                error.ToString(CultureInfo.InvariantCulture) + ".");
        }
    }

    private static void WriteStreamHeader(BinaryWriter writer)
    {
        // BinaryWriter writes these numeric fields in little-endian order.
        writer.Write(Encoding.ASCII.GetBytes("NCM1"));
        writer.Write(48000u); writer.Write(2u); writer.Write(16u);
        writer.Flush();
        CheckOutputPipe();
    }

    private static void WriteStreamPacket(BinaryWriter writer, uint frames, uint flags,

    {
        writer.Write(frames); writer.Write(flags); writer.Write(receivedSeconds);

        writer.Flush();

    {

                                if ((flags & 2u) != 0) silentPackets++;
                                if ((flags & 4u) != 0) timestampErrors++;
                            }

                        if (streamMode && !stopRequested && (seconds == 0 || elapsed < seconds) &&

                            WriteStreamPacket(writer, 0, 0, elapsed, null);
                            lastStreamPacketSeconds = elapsed;
                        }
                    }
                }
                finally
                {
                    lock (captureGate)
                    {
                        if (running) { audio.Stop(); running = false; }
                        clock.Stop();
                    }
                    if (!streamMode) WriteHeader(writer, checked((uint)dataBytes));
                }
                // Exceptions (including a disconnected reader) stop capture via finally,
                // but must not produce a misleading normal-end packet.
                if (streamMode) WriteStreamPacket(writer, 0, 0x80000000u, clock.Elapsed.TotalSeconds, null);
            }

            statistics.WriteLine(string.Format(CultureInfo.InvariantCulture,
                "{{\"target_pid\":{0},\"capture_scope\":\"process_tree_include\",\"wall_seconds\":{1:F4},\"audio_seconds\":{2:F4},\"packets\":{3},\"silent_packets\":{4},\"discontinuities\":{5},\"timestamp_errors\":{6},\"first_packet_ms\":{7:F3},\"max_packet_gap_ms\":{8:F3}",

                silentPackets, discontinuities, timestampErrors, firstPacketMs, maxPacketGapMs) + "}");
            return 0;
        }
        finally
        {
            Console.CancelKeyPress -= cancelHandler;
            lock (captureGate)
            {
                if (running && audio != null) { audio.Stop(); running = false; }
            }
            if (capture != null) Marshal.ReleaseComObject(capture);
            if (audio != null) Marshal.ReleaseComObject(audio);
            if (operation != null) Marshal.ReleaseComObject(operation);
            if (activationMemory != IntPtr.Zero) Marshal.FreeHGlobal(activationMemory);
            ready.Dispose();
            handler.Done.Dispose();
            GC.KeepAlive(handler);
        }
    }

"""Incremental, local-only PCM16 music-change heuristics.

Events describe acoustic evidence, NOT chorus boundaries, emotion, song position,
or actual player pause actions. Times are relative to the capture/replay session.
`event_time_s` is when a condition first passed its threshold; `detected_at_s`
includes the confirmation window. Neither is a measured end-to-end audio latency.

Usage:
    detector = AudioChangeDetector(sample_rate=48000, channels=2)
    for event in detector.feed_pcm16(pcm_bytes):
        consume(event.to_dict())

Call reset() when capture packets are lost. Never replace missing packets with
zeroes: a capture failure must not be interpreted as musical silence.
"""
from __future__ import annotations

from collections import deque
from dataclasses import asdict, dataclass, field
import math
from typing import Any

import numpy as np


@dataclass(frozen=True)
class DetectorConfig:
    hop_seconds: float = 0.05
    silence_dbfs: float = -60.0
    resume_dbfs: float = -52.0
    silence_hold_seconds: float = 0.7
    resume_hold_seconds: float = 0.25
    history_seconds: float = 8.0
    baseline_seconds: float = 4.0
    baseline_guard_seconds: float = 1.0
    minimum_baseline_seconds: float = 2.0
    recent_seconds: float = 0.4
    energy_rise_db: float = 6.0
    energy_drop_db: float = 8.0
    change_hold_seconds: float = 0.5
    texture_distance: float = 0.38
    texture_hold_seconds: float = 0.6
    rhythm_window_seconds: float = 1.5
    rhythm_ratio: float = 1.8
    rhythm_delta_per_second: float = 1.0
    rhythm_hold_seconds: float = 0.5
    event_cooldown_seconds: float = 8.0
    global_change_cooldown_seconds: float = 1.5

    def __post_init__(self) -> None:
        for name, value in asdict(self).items():
            if not math.isfinite(value):
                raise ValueError(f"{name} must be finite")
        positive = [name for name in asdict(self) if name not in ("silence_dbfs", "resume_dbfs")]
        if any(getattr(self, name) <= 0 for name in positive):
            raise ValueError("Durations and detection thresholds must be positive")
        if not 0.01 <= self.hop_seconds <= 0.1:
            raise ValueError("hop_seconds must be between 0.01 and 0.1")
        if not self.silence_dbfs < self.resume_dbfs < 0:
            raise ValueError("Require silence_dbfs < resume_dbfs < 0")
        if self.history_seconds < self.baseline_seconds + self.baseline_guard_seconds:
            raise ValueError("History must contain the baseline and guard window")
        if self.minimum_baseline_seconds > self.baseline_seconds:
            raise ValueError("Minimum baseline cannot exceed the baseline window")
        if not 0 < self.texture_distance < 1:
            raise ValueError("texture_distance must be between 0 and 1")


@dataclass(frozen=True)
class ChangeEvent:
    type: str
    event_time_s: float
    detected_at_s: float
    stream_epoch: int
    evidence: dict[str, Any] = field(default_factory=dict)
    time_basis: str = "capture_session_seconds"

    def to_dict(self) -> dict[str, Any]:
        value = asdict(self)
        value["event_time_s"] = round(self.event_time_s, 4)
        value["detected_at_s"] = round(self.detected_at_s, 4)
        value["confirmation_seconds"] = round(max(0.0, self.detected_at_s - self.event_time_s), 4)
        return value


@dataclass
class _Feature:
    end: float
    db: float
    bands: np.ndarray
    onset: bool


class AudioChangeDetector:
    """Stateful bounded-history detector; keep one instance per capture stream."""

    def __init__(self, sample_rate: int = 48000, channels: int = 2,
                 config: DetectorConfig | None = None, *, start_seconds: float = 0.0) -> None:
        if not 8000 <= sample_rate <= 192000 or not 1 <= channels <= 8:
            raise ValueError("Unsupported sample rate or channel count")
        if not math.isfinite(start_seconds) or start_seconds < 0:
            raise ValueError("start_seconds must be finite and nonnegative")
        self.sample_rate = sample_rate
        self.channels = channels
        self.config = config or DetectorConfig()
        self.hop_frames = round(sample_rate * self.config.hop_seconds)
        self.hop_seconds = self.hop_frames / sample_rate
        self._window = np.hanning(self.hop_frames).astype(np.float32)[:, None]
        self._fft_size = 1 << (self.hop_frames - 1).bit_length()
        frequencies = np.fft.rfftfreq(self._fft_size, 1 / sample_rate)
        edges = [0, 80, 200, 500, 1000, 2500, 6000, 12000, sample_rate / 2 + 1]
        edges = sorted(set(x for x in edges if x <= sample_rate / 2 + 1))
        self._band_masks = [(frequencies >= a) & (frequencies < b) for a, b in zip(edges, edges[1:])]
        self._history: deque[_Feature] = deque(maxlen=math.ceil(self.config.history_seconds / self.hop_seconds) + 2)
        self._pending: dict[str, float] = {}
        self._last_event: dict[str, float] = {}
        self._last_change = -math.inf
        self._origin = start_seconds
        self._frames = 0
        self._buffer = np.empty((0, channels), dtype=np.float32)
        self._previous_db: float | None = None
        self._previous_bands: np.ndarray | None = None
        self._last_onset = -math.inf
        self.stream_epoch = 0
        self.state = "initializing"
        self.last_features: dict[str, Any] = {}
        self.feature_frames = 0

    @property
    def time_seconds(self) -> float:
        return self._origin + self._frames / self.sample_rate

    def reset(self, at_seconds: float, reason: str = "capture_discontinuity") -> ChangeEvent:
        if not math.isfinite(at_seconds) or at_seconds < self.time_seconds - 1e-6:
            raise ValueError("Reset time must be finite and cannot move backwards")
        self.stream_epoch += 1
        self._origin = at_seconds
        self._frames = 0
        self._buffer = np.empty((0, self.channels), dtype=np.float32)
        self._history.clear()
        self._pending.clear()
        self._last_event.clear()
        self._last_change = -math.inf
        self._previous_db = None
        self._previous_bands = None
        self._last_onset = -math.inf
        self.state = "initializing"
        self.last_features = {}
        return ChangeEvent("capture_gap", at_seconds, at_seconds, self.stream_epoch, {"reason": reason})

    def feed_pcm16(self, pcm: bytes) -> list[ChangeEvent]:
        if len(pcm) % (2 * self.channels):
            raise ValueError("PCM chunk must contain complete interleaved frames")
        if not pcm:
            return []
        samples = np.frombuffer(pcm, dtype="<i2").reshape(-1, self.channels).astype(np.float32) / 32768.0
        return self.feed(samples)

    def feed(self, samples: np.ndarray) -> list[ChangeEvent]:
        samples = np.asarray(samples, dtype=np.float32)
        if samples.ndim == 1 and self.channels == 1:
            samples = samples[:, None]
        if samples.ndim != 2 or samples.shape[1] != self.channels:
            raise ValueError("Expected an array with shape (frames, channels)")
        if not np.isfinite(samples).all() or (samples.size and np.max(np.abs(samples)) > 1.0001):
            raise ValueError("Samples must be finite normalized values in [-1, 1]")
        self._buffer = np.concatenate((self._buffer, samples), axis=0)
        events: list[ChangeEvent] = []
        consumed = 0
        while consumed + self.hop_frames <= len(self._buffer):
            block = self._buffer[consumed:consumed + self.hop_frames]
            self._frames += self.hop_frames
            feature = self._extract(block, self.time_seconds)
            events.extend(self._advance(feature))
            self.feature_frames += 1
            consumed += self.hop_frames
        self._buffer = self._buffer[consumed:].copy()
        return events

    def _extract(self, block: np.ndarray, end: float) -> _Feature:
        # Average CHANNEL POWERS, not channels themselves; antiphase stereo must
        # not disappear through a naive mono downmix.
        rms = float(np.sqrt(np.mean(block.astype(np.float64) ** 2)))
        db = max(-120.0, 20 * math.log10(max(rms, 1e-6)))
        fft = np.fft.rfft(block * self._window, n=self._fft_size, axis=0)
        power = np.mean(np.abs(fft) ** 2, axis=1)
        bands = np.array([float(power[mask].sum()) for mask in self._band_masks])
        bands /= max(float(bands.sum()), 1e-20)
        db_jump = db - self._previous_db if self._previous_db is not None else 0.0
        flux = float(np.maximum(bands - self._previous_bands, 0).sum()) if self._previous_bands is not None else 0.0
        onset = (db > self.config.resume_dbfs and end - self._last_onset >= 0.12
                 and (db_jump >= 4.0 or (flux >= 0.2 and db_jump >= 1.5)))
        if onset:
            self._last_onset = end
        self._previous_db, self._previous_bands = db, bands
        return _Feature(end, db, bands, onset)

    def _confirmed(self, name: str, condition: bool, end: float, hold: float) -> float | None:
        if not condition:
            self._pending.pop(name, None)
            return None
        since = self._pending.setdefault(name, end - self.hop_seconds)
        return since if end - since >= hold - 1e-8 else None

    def _emit(self, name: str, since: float, end: float, evidence: dict[str, Any]) -> ChangeEvent:
        self._pending.pop(name, None)
        self._last_event[name] = end
        return ChangeEvent(name, max(0.0, since), end, self.stream_epoch, evidence)

    def _advance(self, current: _Feature) -> list[ChangeEvent]:
        c, now = self.config, current.end
        self.last_features = {"rms_dbfs": round(current.db, 2), "onset": current.onset}
        quiet_since = self._confirmed("quiet", current.db < c.silence_dbfs, now, c.silence_hold_seconds)
        audible_since = self._confirmed("audible", current.db > c.resume_dbfs, now, c.resume_hold_seconds)
        if self.state != "silence" and quiet_since is not None:
            self.state = "silence"
            self._history.clear()
            self._pending.clear()
            return [self._emit("silence_start", quiet_since, now, {"rms_dbfs": round(current.db, 2), "interpretation": "silence_or_pause_candidate"})]
        if self.state != "audio" and audible_since is not None:
            previous = self.state
            self.state = "audio"
            self._history.clear()
            self._pending.clear()
            self._history.append(current)
            return [self._emit("audio_resumed" if previous == "silence" else "audio_started", audible_since, now,
                               {"rms_dbfs": round(current.db, 2)})]
        if self.state != "audio" or current.db < c.silence_dbfs:
            for key in ("energy_rise", "energy_drop", "texture_change", "rhythm_change"):
                self._pending.pop(key, None)
            return []
        self._history.append(current)
        history = list(self._history)
        baseline = [f for f in history if now - c.baseline_guard_seconds - c.baseline_seconds < f.end <= now - c.baseline_guard_seconds + 1e-8]
        recent = [f for f in history if f.end > now - c.recent_seconds + 1e-8]
        if len(baseline) * self.hop_seconds < c.minimum_baseline_seconds - 1e-8 or not recent:
            return []
        base_db = float(np.median([f.db for f in baseline]))
        recent_db = float(np.median([f.db for f in recent]))
        delta_db = recent_db - base_db
        base_bands = np.median(np.stack([f.bands for f in baseline]), axis=0)
        new_bands = np.median(np.stack([f.bands for f in recent]), axis=0)
        base_bands /= max(float(base_bands.sum()), 1e-20)
        new_bands /= max(float(new_bands.sum()), 1e-20)
        distance = float(np.abs(new_bands - base_bands).sum() / 2)
        rhythm_recent = [f for f in history if f.end > now - c.rhythm_window_seconds + 1e-8]
        rhythm_base = [f for f in history if now - c.rhythm_window_seconds - c.baseline_seconds < f.end <= now - c.rhythm_window_seconds + 1e-8]
        rhythm_ready = len(rhythm_base) * self.hop_seconds >= c.minimum_baseline_seconds - 1e-8
        onset_rate = sum(f.onset for f in rhythm_recent) / max(self.hop_seconds, len(rhythm_recent) * self.hop_seconds)
        base_rate = sum(f.onset for f in rhythm_base) / max(self.hop_seconds, len(rhythm_base) * self.hop_seconds)
        ratio = (onset_rate + 0.25) / (base_rate + 0.25)
        rhythm_change = rhythm_ready and abs(onset_rate - base_rate) >= c.rhythm_delta_per_second and (ratio >= c.rhythm_ratio or ratio <= 1 / c.rhythm_ratio)
        evidence = {
            "rms_dbfs": round(recent_db, 2), "baseline_rms_dbfs": round(base_db, 2),
            "delta_db": round(delta_db, 2), "spectral_distance": round(distance, 4),
            "onsets_per_second": round(onset_rate, 3), "baseline_onsets_per_second": round(base_rate, 3),
        }
        self.last_features.update(evidence)
        candidates = [
            ("energy_rise", delta_db >= c.energy_rise_db, c.change_hold_seconds),
            ("energy_drop", delta_db <= -c.energy_drop_db, c.change_hold_seconds),
            ("texture_change", distance >= c.texture_distance, c.texture_hold_seconds),
            ("rhythm_change", rhythm_change, c.rhythm_hold_seconds),
        ]
        ready = []
        for name, condition, hold in candidates:
            since = self._confirmed(name, condition, now, hold)
            if since is not None and now - self._last_event.get(name, -math.inf) >= c.event_cooldown_seconds:
                ready.append((name, since))
        if ready and now - self._last_change >= c.global_change_cooldown_seconds:
            name, since = ready[0]
            self._last_change = now
            return [self._emit(name, since, now, evidence)]
        return []

@dataclass
class Packet:
    frames: int
    flags: int
    received_seconds: float
    pcm: bytes
    queued_at: float = 0.0
    sequence: int = 0


def sequence_gap(previous: int | None, current: int) -> bool:
    """Consumer ordering, not a producer's future cumulative drop count."""
    return current != (0 if previous is None else previous + 1)


def read_exact(stream: BinaryIO, size: int) -> bytes:
    data = bytearray()
    while len(data) < size:
        piece = stream.read(size - len(data))
        if not piece:
            raise EOFError(f"Audio stream truncated: expected {size}, received {len(data)} bytes")
        data.extend(piece)
    return bytes(data)


def read_header(stream: BinaryIO) -> tuple[int, int]:
    magic, rate, channels, bits = STREAM_HEADER.unpack(read_exact(stream, STREAM_HEADER.size))
    if magic != b"NCM1" or rate != 48000 or channels != 2 or bits != 16:
        raise ValueError("Unsupported capture protocol or audio format")
    return rate, channels


def read_packet(stream: BinaryIO, rate: int, channels: int) -> Packet:
    frames, flags, received = PACKET_HEADER.unpack(read_exact(stream, PACKET_HEADER.size))
    if frames > rate or not math.isfinite(received) or received < 0:
        raise ValueError("Invalid capture packet length/timestamp")
    if flags & END_FLAG and frames:
        raise ValueError("End packet must not contain PCM")
    pcm = read_exact(stream, frames * channels * 2) if frames else b""
    return Packet(frames, flags, received, pcm, time.perf_counter())

def replay(path: Path, config: DetectorConfig, reporter: Reporter) -> dict:
    begin = time.perf_counter()
    frames_read = 0
    maximum_block_ms = 0.0
    with wave.open(str(path), "rb") as wav:
        if wav.getsampwidth() != 2 or wav.getcomptype() != "NONE":
            raise ValueError("回放只支持未压缩 PCM16 WAV")
        rate, channels = wav.getframerate(), wav.getnchannels()
        detector = AudioChangeDetector(rate, channels, config)
        reporter.write({"kind": "session", "mode": "wav_replay", "input": str(path.resolve()),
                        "sample_rate": rate, "channels": channels, "config": config.__dict__,
                        "time_basis": "capture_session_seconds", "audio_saved": False})
        while True:
            pcm = wav.readframes(4096)
            if not pcm:
                break
            frames_read += len(pcm) // (2 * channels)
            started = time.perf_counter()
            events = detector.feed_pcm16(pcm)
            maximum_block_ms = max(maximum_block_ms, (time.perf_counter() - started) * 1000)
            for event in events:
                reporter.event(event)
        if frames_read != wav.getnframes():
            raise ValueError("WAV 文件不完整：数据帧数与文件头不符")
    return {"mode": "wav_replay", "audio_seconds": round(frames_read / rate, 4),
            "analysis_seconds": round(time.perf_counter() - begin, 4),
            "max_block_processing_ms": round(maximum_block_ms, 3),
            "feature_frames": detector.feature_frames, "events": dict(reporter.counts)}

"""Read the current Windows media session through GSMTC (read-only).

This module does not capture audio, control playback, access account credentials,
or infer song position when Windows does not provide a timeline.

Optional dependency: the PyWinRT Windows.Media.Control projection. Import is lazy
so the rest of the project and its tests remain usable without Windows/PyWinRT.
"""
from __future__ import annotations

import asyncio
import logging
import time
from dataclasses import asdict, dataclass
from typing import Any, AsyncIterator, Callable, Optional

log = logging.getLogger(__name__)


@dataclass(frozen=True)
class MusicContext:
    title: Optional[str] = None
    artist: Optional[str] = None
    album: Optional[str] = None
    playback_status: str = "unknown"
    position_seconds: Optional[float] = None
    position_source: str = "unavailable"
    position_confidence: str = "none"
    duration_seconds: Optional[float] = None
    source_app_id: Optional[str] = None
    sampled_at_monotonic: float = 0.0
    available: bool = False
    error: Optional[str] = None

    def to_dict(self) -> dict[str, Any]:
        return asdict(self)


class GSMTCUnavailableError(RuntimeError):
    """Raised when the Windows GSMTC API cannot be imported or initialized."""


def _enum_name(value: Any) -> str:
    if value is None:
        return "unknown"
    name = getattr(value, "name", None)
    if name:
        return str(name).lower()
    text = str(value).rsplit(".", 1)[-1]
    return text.lower() if text else "unknown"


def _seconds(value: Any) -> Optional[float]:
    if value is None:
        return None
    total = getattr(value, "total_seconds", None)
    if callable(total):
        try:
            result = float(total())
            return result if result >= 0 else None
        except (TypeError, ValueError, OverflowError):
            return None
    # Some projections expose TimeSpan as an integer count of 100 ns ticks.
    try:
        result = float(value) / 10_000_000.0
        return result if result >= 0 else None
    except (TypeError, ValueError, OverflowError):
        return None


class MusicContextReader:
    """Poll the current GSMTC session without touching the audio stream.

    `session_manager` is injectable for tests. Production initialization uses
    `await MusicContextReader.create()`. By default, sessions whose source app
    id does not contain `cloudmusic` are rejected to avoid reading another app.
    Set `source_app_tokens=()` only if the local Windows installation exposes
    a different, verified app id.
    """

    def __init__(
        self,
        session_manager: Any,
        *,
        source_app_tokens: tuple[str, ...] = ("cloudmusic",),
    ) -> None:
        self._manager = session_manager
        self._source_app_tokens = tuple(t.casefold() for t in source_app_tokens)

    @classmethod
    async def create(
        cls,
        *,
        source_app_tokens: tuple[str, ...] = ("cloudmusic",),
    ) -> "MusicContextReader":
        try:
            from winrt.windows.media.control import (  # type: ignore[import-not-found]
                GlobalSystemMediaTransportControlsSessionManager,
            )
        except Exception as exc:  # Import errors vary by PyWinRT distribution.
            raise GSMTCUnavailableError(
                "PyWinRT Windows.Media.Control is unavailable. Install a compatible "
                "PyWinRT projection on Windows, then retry."
            ) from exc
        try:
            manager = await GlobalSystemMediaTransportControlsSessionManager.request_async()
        except Exception as exc:
            raise GSMTCUnavailableError(f"GSMTC initialization failed: {exc}") from exc
        return cls(manager, source_app_tokens=source_app_tokens)

    def _is_target_app(self, app_id: Optional[str]) -> bool:
        if not self._source_app_tokens:
            return True
        if not app_id:
            return False
        folded = app_id.casefold()
        return any(token in folded for token in self._source_app_tokens)

    async def read(self) -> MusicContext:
        """Read one snapshot. API failures are returned as an unavailable context."""
        sampled = time.monotonic()
        try:
            session = self._manager.get_current_session()
            if session is None:
                return MusicContext(sampled_at_monotonic=sampled)

            app_id = getattr(session, "source_app_user_model_id", None)
            if not self._is_target_app(app_id):
                return MusicContext(
                    source_app_id=str(app_id) if app_id else None,
                    sampled_at_monotonic=sampled,
                )

            playback = session.get_playback_info()
            status_obj = getattr(playback, "playback_status", None)
            status = _enum_name(status_obj)

            media = await session.try_get_media_properties_async()
            timeline = session.get_timeline_properties()
            position = _seconds(getattr(timeline, "position", None))
            duration = _seconds(getattr(timeline, "end_time", None))

            return MusicContext(
                title=_clean(getattr(media, "title", None)),
                artist=_clean(getattr(media, "artist", None)),
                album=_clean(getattr(media, "album_title", None)),
                playback_status=status,
                position_seconds=position,
                position_source="gsmTC_timeline" if position is not None else "unavailable",
                position_confidence="system_reported" if position is not None else "none",
                duration_seconds=duration,
                source_app_id=str(app_id) if app_id else None,
                sampled_at_monotonic=sampled,
                available=True,
            )
        except asyncio.CancelledError:
            raise
        except Exception as exc:
            log.warning("GSMTC read failed: %s", exc)
            return MusicContext(sampled_at_monotonic=sampled, error=f"{type(exc).__name__}: {exc}")

    async def watch(
        self,
        *,
        interval_seconds: float = 1.0,
        include_position_updates: bool = False,
    ) -> AsyncIterator[MusicContext]:
        """Yield snapshots on track/status changes; optionally yield position ticks."""
        if interval_seconds < 0.2:
            raise ValueError("interval_seconds must be >= 0.2")
        previous_key: Any = object()
        while True:
            context = await self.read()
            key = (
                context.title,
                context.artist,
                context.playback_status,
                context.source_app_id,
                context.available,
                context.error,
            )
            if include_position_updates:
                key += (None if context.position_seconds is None else round(context.position_seconds, 1),)
            if key != previous_key:
                yield context
                previous_key = key
            await asyncio.sleep(interval_seconds)


def _clean(value: Any) -> Optional[str]:
    if value is None:
        return None
    value = str(value).strip()
    return value or None


async def read_current_music_context() -> MusicContext:
    """Convenience one-shot read using the real Windows GSMTC API."""
    reader = await MusicContextReader.create()
    return await reader.read()

def tone(seconds, amplitude=0.1, frequency=440):
    t = np.arange(round(seconds * RATE)) / RATE
    return (amplitude * np.sin(2 * np.pi * frequency * t)).astype(np.float32)


def pulses(seconds, hz):
    t = np.arange(round(seconds * RATE)) / RATE
    envelope = 0.025 + 0.18 * np.exp(-40 * (t % (1 / hz)))
    return (envelope * np.sin(2 * np.pi * 440 * t)).astype(np.float32)


def run_signal(signal, config=None, chunk=2400):

    events = []
    for start in range(0, len(signal), chunk):
        events.extend(detector.feed(signal[start:start + chunk]))
    return detector, events

    def test_future_queue_drops_do_not_reset_inflight_contiguous_packet(self):
        allow_producer = threading.Event()
        filled = threading.Event()

        class FutureOverflowQueue(queue.Queue):
            def put_nowait(self, packet):
                if packet.sequence == 2 and not allow_producer.wait(2):
                    raise RuntimeError("consumer did not release producer")
                super().put_nowait(packet)
                if packet.sequence == 69:
                    filled.set()

            def get(self, block=True, timeout=None):
                packet = super().get(block=block, timeout=timeout)
                if block and packet.sequence == 1:
                    # Hold sequence 1 in flight while the producer drops 2..5.
                    # It remains contiguous with 0: reset only when 6 is consumed.
                    allow_producer.set()
                    if not filled.wait(2):
                        raise RuntimeError("producer did not complete overflow")
                return packet

        result, gaps = self._run_queue_loss(FutureOverflowQueue)
        self.assertEqual(result["queue_dropped_packets"], 4)
        self.assertEqual(len(gaps), 1)
        self.assertEqual(gaps[0]["evidence"]["reason"], "packet_sequence_gap")
        self.assertAlmostEqual(gaps[0]["detected_at_s"], 0.06)
        self.assertAlmostEqual(result["audio_seconds"], 0.66)

Python 3.10+ / Windows 11. No pip packages needed.
  python test_netease_audio.py                     # capture 10 seconds
  python test_netease_audio.py --seconds 15        # up to 30 seconds
  python test_netease_audio.py --analyze clip.wav   # no recording

No microphone capture, client modification, login access, or uploads.
A detected signal is NOT proof of music content, song identity, or sync accuracy.

from __future__ import annotations

import argparse
import array

import json
import math
import os

BASE = Path(__file__).resolve().parent


def find_cloudmusic_pid() -> int:
    command = (
        "[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new(); "
        "@(Get-CimInstance Win32_Process -Filter \"Name='cloudmusic.exe'\" | "
        "Select-Object ProcessId,ParentProcessId) | ConvertTo-Json -Compress"
    )
    result = subprocess.run(
        ["powershell.exe", "-NoProfile", "-Command", command],
        capture_output=True, encoding="utf-8-sig", check=True, timeout=20,
    )
    rows = json.loads(result.stdout) if result.stdout.strip() else []
    if isinstance(rows, dict):
        rows = [rows]
    ids = {row["ProcessId"] for row in rows}
    roots = [row["ProcessId"] for row in rows if row["ParentProcessId"] not in ids]
    if not roots:
        raise RuntimeError("未找到网易云音乐，请先启动客户端并播放歌曲。")
    if len(roots) != 1:
        raise RuntimeError(f"发现多个网易云主进程 {roots}，请用 --pid 指定目标。")
    return roots[0]


def ensure_helper() -> Path:
    source = BASE / "ProcessLoopback.cs"
    executable = BASE / "ProcessLoopback.exe"
    if not executable.exists() or source.stat().st_mtime > executable.stat().st_mtime:
        compiler = Path(os.environ.get("WINDIR", r"C:\Windows")) / "Microsoft.NET/Framework64/v4.0.30319/csc.exe"
        if not compiler.is_file():
            raise RuntimeError("未找到系统 .NET Framework x64 C# 编译器。")
        subprocess.run(
            [str(compiler), "-nologo", "-platform:x64", "-optimize+", f"-out:{executable}", str(source)],
            check=True, timeout=30, stdout=sys.stderr,
        )
    return executable


def dbfs(value: float) -> float | None:
    return round(20 * math.log10(value), 2) if value > 0 else None


def analyze(path: Path) -> dict:
    with wave.open(str(path), "rb") as wav:
        rate, channels, width = wav.getframerate(), wav.getnchannels(), wav.getsampwidth()
        frames = wav.getnframes()
        if width != 2 or wav.getcomptype() != "NONE":
            raise ValueError("分析器只支持未压缩 PCM16 WAV。")
        if frames * channels * width > 128 * 1024 * 1024:
            raise ValueError("测试分析器只接受小于 128 MiB 的音频。")
        raw = wav.readframes(frames)
    if len(raw) != frames * channels * width:
        raise ValueError("WAV 数据比文件头声明的帧数短，文件可能未写完。")
    samples = array.array("h", raw)
    if sys.byteorder != "little":
        samples.byteswap()
    count = len(samples)
    peak = max((abs(x) for x in samples), default=0) / 32768
    rms = math.sqrt(sum(x * x for x in samples) / count) / 32768 if count else 0
    threshold = 10 ** (-65 / 20)
    windows = []
    hop = rate * channels
    for start in range(0, count, hop):
        chunk = samples[start:start + hop]
        level = math.sqrt(sum(x * x for x in chunk) / len(chunk)) / 32768
        windows.append({"start_seconds": start / hop, "rms_dbfs": dbfs(level)})
    clipped = sum(x >= 32767 or x <= -32768 for x in samples)
    if not count:
        status = "no_audio_frames"
    elif rms < threshold:
        status = "near_silence"
    else:
        status = "signal_detected"
    return {
        "file": str(path.resolve()), "sample_rate": rate, "channels": channels,
        "bits_per_sample": width * 8, "frames": frames, "duration_seconds": frames / rate,
        "rms_dbfs": dbfs(rms), "peak_dbfs": dbfs(peak),
        "clipped_samples": clipped, "clipped_fraction": clipped / count if count else 0,
        "signal_status": status, "near_silence_threshold_dbfs": -65,
        "per_second_levels": windows,
        "limitations": [
            "信号阈值是测试启发式；检测到信号不等于已经识别出音乐或歌名。",
            "进程包含过滤已启用，但本测试未进行其它应用声音的对照隔离实验。",
            "音频包到达间隔不是从扬声器发声到AI开口的端到端延迟。",
        ],
    }
